CampusConnect – Smart Student Hub

CampusConnect is a student-focused web application designed to bring essential campus activities and services together in one place.

It helps students stay updated, participate in campus activities, connect with clubs, and access useful student services.

Features

- User Authentication: Student registration and login.
- Student Hub: A central dashboard for students.
- Clubs: Explore clubs and manage student-specific joining status.
- Events: Add, search, and manage campus events.
- Notices: View and manage important announcements.
- Lost & Found: Report and find lost items.
- Help Desk: Submit and manage campus-related queries.
- Responsive Design: User-friendly interface for different screen sizes.

Tech Stack

- Frontend: React.js, Vite
- Backend: Node.js, Express.js
- Database: MongoDB
- Programming Languages: JavaScript, HTML, CSS

Getting Started

1. Clone the repository.
2. Install dependencies in the Backend and Frontend folders using "npm install".
3. Configure your local environment variables.
4. Start the backend server using "node server.js".
5. Start the frontend using "npm run dev" from the Frontend folder.

Project Goal

The goal of CampusConnect is to make campus communication and student services more accessible through a single web application.
